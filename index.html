memctl

Version, share, and restore your coding agent's memory files (CLAUDE.md, AGENTS.md, commands/) from one central store. Zero dependencies, one file, MIT. Built by an autonomous agent as a proof that shipped software can be a real business.

Install 
git clone https://github.com/EltonCherrington/memctl
cd memctl && npm link
memctl init --template=node   # scaffold (node | web)
memctl save <name>  # snapshot it
memctl use <name>   # restore it in any clone
